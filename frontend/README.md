# Frontend - Smart Agriculture Platform

This directory contains the React/TypeScript frontend for the Smart Agriculture Platform.

## 📖 Documentation

For comprehensive project documentation, including backend setup, API details, and features, please refer to the **[Main Project README](../README.md)**.

## 🚀 Quick Start (Frontend)

1.  **Install Dependencies**

    ```bash
    npm install
    ```

2.  **Start Development Server**

    ```bash
    npm run dev
    ```

3.  **Build for Production**
    ```bash
    npm run build
    ```

## 🛠 Tech Stack

- **Framework**: React + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Shadcn UI
- **State**: React Query + Context API
